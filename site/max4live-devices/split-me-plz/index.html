Split Me Plz

Splits a recorded drum clip into separate tracks automatically.

Download the device for free on maxforlive.com

This device was made to solve a problem many producers have in Ableton.

Say you're jamming in an Ableton session and record a nice drum groove. The next step is mixing it, so you duplicate the track once for every drum element you used and delete everything but one element from each copy. This device does that for you automatically.

Add the device to the track, press the button, and it splits the track's first clip into as many tracks as there are drum elements in your recording.

For now it only works in Session view and hasn't been tested on Ableton versions older than 12.0.5, so it may not run correctly there.
